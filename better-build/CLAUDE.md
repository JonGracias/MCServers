# better-build pack

Near-vanilla survival pack: Minecraft **1.21.11** / Fabric loader **0.19.3**, one mod.

| Mod | Why | Notes |
|---|---|---|
| [Effortless Building](https://modrinth.com/mod/effortless-building) 4.1 | building QoL: mirrors, arrays, build modes, block randomizer — works in survival | needed on BOTH server and client; no dependencies (no Fabric API required) |

Server: Jon's laptop, `10.0.0.172:25567`, survival / normal difficulty, whitelist on.

Everything else is vanilla — no voice chat, no ReplayMod in this pack.
